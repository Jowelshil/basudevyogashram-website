আমন্ত্রণ SMS

আশ্রমের বার্ষিক অনুষ্ঠানগুলো একবার লিখে রাখুন। প্রতি বছর অনুষ্ঠানের আগে "আমন্ত্রণ পাঠান" চাপলেই মাসিক প্রণামী দাতা, ভূমিদাতা ও আজীবন সদস্যদের মোবাইলে আমন্ত্রণ যাবে।

SMS সেটিংস (Robi)

Robi থেকে বাল্ক SMS অ্যাকাউন্ট নিলে তারা একটা API লিংক, ইউজারনেম/পাসওয়ার্ড বা API key দেবে। নিচে সেগুলো বসান। প্যারামিটারে {to} মানে দাতার মোবাইল নম্বর আর {msg} মানে বার্তা, এগুলো নিজে থেকে বসে যাবে।
