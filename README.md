# বাসুদেব যোগাশ্রম হিসাব অ্যাপ (Android)

এই ব্রাঞ্চে শুধু Android অ্যাপের খোলস আছে। অ্যাপটি খোলে https://basudevyogashram.org/app/ পাতাটি,
যার কোড `main` ব্রাঞ্চের `app/` ফোল্ডারে। তাই হিসাবের পাতায় কোনো পরিবর্তন হলে অ্যাপ নতুন করে ইনস্টল করতে হয় না।

এই ব্রাঞ্চে push করলে GitHub Actions নিজে থেকে APK বানিয়ে Releases-এ রাখে।
সর্বশেষ APK: https://github.com/Jowelshil/basudevyogashram-website/releases/latest/download/BasudevYogashram.apk
