# শ্রীশ্রী বাসুদেব যোগাশ্রম — ওয়েবসাইট

basudevyogashram.org-এর সোর্স ফাইল। শ্রীশ্রী বাসুদেব যোগাশ্রম ও বাসুদেব অনাথ আশ্রম, নেহালপুর, নন্দীরহাট, হাটহাজারী, চট্টগ্রাম।

- `index.html` — পুরো ওয়েবসাইট (এক পাতা)
- `images/` — সব ছবি; `images/bhumidata/` — ভূমিদাতাদের ছবি

`main` ব্রাঞ্চে পরিবর্তন হলে Hostinger Git auto-deployment-এর মাধ্যমে সাইট নিজে থেকেই আপডেট হয় (public_html)।
